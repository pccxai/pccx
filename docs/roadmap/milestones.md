# Milestones

We are improving the development setup and documentation so SystemVerilog
developers can start with a small test. See {doc}`../roadmap` for the full plan.

## Priorities

1. Review existing issues and PRs, choose upcoming work and agree on owners.
2. Reduce external tool dependencies in the simulation runner and document the test setup.
3. Prepare small verification issues with commands and expected results.
4. Improve the testing and PR guides with feedback from first-time contributors.

We will share dates in [GitHub Projects](https://github.com/orgs/pccxai/projects/1)
once the scope and owners are agreed. KV260 runtime and v003 architecture
work are discussed in their respective repositories.
