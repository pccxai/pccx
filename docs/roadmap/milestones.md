# Milestones

The current public participation goals and completion criteria live in
{doc}`../roadmap`. The first objective is a reproducible small test and
reviewable PR for a SystemVerilog RTL or verification developer.

## Order and completion criteria

1. Reconcile retired-tool work and current issues/PRs; identify owners and scope.
2. Remove the Lab dependency and validate a public RTL test from a clean checkout.
3. Prepare small verification issues with commands, expected results and reviewers.
4. Have an external contributor test, submit a PR and complete review; fix obstacles.

Dates are not assigned. These goals are not already completed milestones.
pccx-lab, SystemVerilog IDE and PCCX Launcher are discontinued and excluded.

Board runtime and later architecture research remain separate technical work.
Existing [GitHub Projects](https://github.com/orgs/pccxai/projects/1) statuses
and milestones require reconciliation. Original experiment and release dates
remain historical records.
