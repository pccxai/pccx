# 마일스톤

현재의 공개 참여 목표와 완료 기준은 {doc}`../roadmap`에서 관리합니다.
SystemVerilog RTL·검증 개발자가 작은 테스트를 재현하고 PR을 제출할 수
있는 경로를 먼저 정비합니다.

## 순서와 완료 기준

1. 폐지 도구 작업과 현행 이슈·PR을 정리하고 담당자와 범위를 지정합니다.
2. Lab 의존성을 제거한 공개 RTL 테스트 경로를 새 checkout에서 검증합니다.
3. 재현 명령·예상 결과·리뷰 담당자가 있는 작은 검증 이슈를 준비합니다.
4. 외부 기여자가 테스트부터 PR·리뷰까지 수행하고 막힌 지점을 개선합니다.

목표일은 미정입니다. 이 항목들을 이미 완료된 것으로 표시하지 않습니다.
pccx-lab, SystemVerilog IDE, PCCX Launcher는 폐지되었으며 새 일정에 포함하지 않습니다.

보드 런타임과 후속 아키텍처 연구는 별도의 기술 과제로 관리합니다.
기존 [GitHub Projects](https://github.com/orgs/pccxai/projects/1)의 과거 상태와
마일스톤은 새 방향에 맞춰 재검토할 대상입니다. 원래 실험일과 릴리스 날짜는 보존합니다.
