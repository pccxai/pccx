# 마일스톤

SystemVerilog 개발자가 작은 테스트부터 기여할 수 있도록 개발 환경과 문서를
정리하고 있습니다. 자세한 계획은 {doc}`../roadmap`을 참고하세요.

## 우선순위

1. 기존 이슈와 PR을 검토하고 진행할 작업과 담당자를 정합니다.
2. 시뮬레이션 실행기의 외부 도구 의존성을 줄이고 테스트 방법을 정리합니다.
3. 실행 명령과 예상 결과가 적힌 작은 검증 이슈를 준비합니다.
4. 처음 참여한 개발자의 피드백을 받아 테스트와 PR 작성 가이드를 개선합니다.

구체적인 일정은 작업 범위와 담당자를 정한 뒤
[GitHub Projects](https://github.com/orgs/pccxai/projects/1)에서 공유합니다.
KV260 보드 런타임과 v003 아키텍처 개발은 각 저장소의 이슈에서 논의합니다.
